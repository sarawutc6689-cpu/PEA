Dashboard

หน้าแรกแสดงภาพรวมของระบบ ได้แก่ จำนวนบิลทั้งหมด, รับบิลแล้ว, รอรับบิล และ จำนวนสถานที่ พร้อมสรุปสถานะแยกตามแต่ละสถานที่ในรูปแบบการ์ด

คลิกที่การ์ดสถานที่ เพื่อดูรายการบิลทั้งหมดของสถานที่นั้น รวมถึงแก้ไข/ลบบิลได้ทันที

รายการบิล / รอรับบิล / รับบิลแล้ว

เมนูด้านซ้ายใช้ดูรายการบิลในรูปแบบตาราง โดยแยกตามสถานะ:

  • รายการบิล — แสดงบิลทั้งหมดในระบบ
  • รอรับบิล — แสดงเฉพาะบิลที่ยังไม่ได้รับ
  • รับบิลแล้ว — แสดงเฉพาะบิลที่รับเรียบร้อยแล้ว
เพิ่ม / แก้ไข / ลบบิล

กดปุ่ม "เพิ่มบิล" มุมขวาบนเพื่อเพิ่มบิลใหม่ กรอกเลขที่บิล สถานที่ รายละเอียด สถานะ และวันที่ (เลขที่บิลต้องไม่ซ้ำกัน)

ในตารางรายการบิล ใช้ไอคอน เพื่อแก้ไข และไอคอน เพื่อลบบิลรายการนั้น

ค้นหาบิล

ใช้ช่องค้นหาด้านซ้าย พิมพ์ เลขท้ายบิลอย่างน้อย 5 ตัว ระบบจะค้นหาให้อัตโนมัติ หรือกด Enter เพื่อค้นหาทันที กด Esc เพื่อล้างการค้นหา

Backup สิ้นเดือน

ใช้สำรองข้อมูลบิลทั้งหมดเก็บไว้แยกตามเดือน (เช่น BACKUP_กรกฎาคม_2569)

หลังจาก Backup สำเร็จ ระบบจะลบข้อมูลทั้งหมดออกจากตารางหลักโดยอัตโนมัติ เพื่อเริ่มรอบบิลใหม่
ประวัติ Backup / ดูข้อมูล Backup

ประวัติ Backup แสดงรายการการสำรองข้อมูลที่เคยทำไว้ทั้งหมด พร้อมวันที่และจำนวนรายการ

ดูข้อมูล Backup ใช้เลือกดูข้อมูลบิลย้อนหลังของแต่ละเดือนที่เคย Backup ไว้ โดยไม่กระทบข้อมูลปัจจุบัน

เคลียร์ข้อมูลทั้งหมด

ใช้รีเซ็ตสถานะและวันที่ของทุกบิลให้ว่าง โดยไม่ลบเลขที่บิล/สถานที่/รายละเอียด

ต้องกรอกรหัสยืนยันก่อนทุกครั้ง และการทำรายการนี้ไม่สามารถย้อนกลับได้
